# Ransomware-Attacks-Dashboard
# 🛡️ Ransomware Attacks Intelligence Dashboard

An interactive dashboard for analyzing ransomware attacks using Python, Pandas, Plotly, and Streamlit.

## 📊 Project Overview

This project analyzes a dataset containing ransomware attack information and provides interactive visualizations to understand attack patterns across different sectors, organization sizes, locations, years, and attack costs.

## 🎯 Objectives

* Analyze ransomware attacks by sector.
* Identify the most targeted sectors.
* Analyze attacks by organization size.
* Explore ransomware attack costs.
* Analyze attack trends over time.
* Provide interactive filtering and data exploration.

## 🛠️ Technologies

* Python
* Pandas
* Streamlit
* Plotly
* Data Visualization
* Cybersecurity Analytics

## 📈 Dashboard Features

* Total number of ransomware attacks
* Number of targeted organizations
* Sector analysis
* Top 10 targeted sectors
* Organization size analysis
* Attack cost analysis
* Dataset preview
* Interactive sector filtering

## 📂 Dataset

The dataset contains information about ransomware attacks, including:

* Target
* Sector
* Organization size
* Revenue
* Attack cost
* Ransom cost
* Ransom paid
* Year
* Month
* Location
* Number of employees
* Source information

## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Ransomware-Attacks-Dashboard.git
```

Open the project folder:

```bash
cd Ransomware-Attacks-Dashboard
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```

The dashboard will open in your browser.
